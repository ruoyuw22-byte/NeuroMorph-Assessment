# Third-party components

NeuroMorph Assessment integrates with software installed separately on the user's computer.
The following components are **not bundled** in this repository:

- MATLAB
- SPM12
- CAT12
- dcm2niix

Users should obtain and install these components from their respective official sources and comply with their respective license terms.

The repository contains only the NMA application source, interface resources, build script, and generic report assets.
